# 🤖 AIHub

### 주제 : AI 시대를 대비하는 **생성형 AI 커뮤니티**

> **AIHub**는 생성형 AI 사용 경험과 인사이트를 공유하고, 유저 간 소통할 수 있는 커뮤니티 플랫폼입니다.  
> 글을 쓰고, 공감(좋아요)을 누르고, 각자의 프로필을 통해 활동을 관리할 수 있습니다.

---

## 👥 멤버

- 김동윤 – 풀스택 개발

---

## 🗓 개발 기간

- **1차 개발** : 2024.11.15 ~ 2024.11.28  
- **2차 리팩토링** : 예정

---

## 🛠 기술 스택

### 🔹 Frontend

- React
- HTML / CSS

### 🔸 Backend

- Spring Boot (Spring Security, JPA)
- MySQL
- Redis

### 🐳 DevOps / 인프라

- Docker & Docker Compose
- Nginx (Reverse Proxy)
- Linux VM 기반 배포

---

## 🧩 주요 기능

| 기능 | 설명 |
|------|------|
| 📝 게시글 작성 | 생성형 AI 경험이나 팁을 글로 공유할 수 있습니다 |
| 👍 좋아요 | 공감하는 글에 좋아요를 눌러 표시할 수 있습니다 |
| 👤 프로필 관리 | 자신의 작성 글과 활동 내역을 확인할 수 있습니다 |
